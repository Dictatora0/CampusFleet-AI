# 严谨的强化学习对比实验 - 使用指南

## 📋 概述

`rl_comparison_rigorous.py` 是一个论文级别的实验脚本，用于严谨地对比 Standard DQN 和 Double DQN 算法。

### 🎯 设计特点

- ✅ **多次独立运行**: 默认 5 次，可自定义
- ✅ **完全收敛**: 1000 episodes/run
- ✅ **统计分析**: 均值、标准差、95% 置信区间
- ✅ **显著性检验**: t 检验（需要 scipy）
- ✅ **专业可视化**: 带误差条的学习曲线、bar 图、box 图
- ✅ **详细报告**: JSON + 文本格式

## 🔧 自定义配置

### 修改训练参数

编辑 `rl_comparison_rigorous.py` 的 `run_single_experiment` 函数：

```python
# 训练配置（严谨版）
training_config = {
    "max_episodes": 1000,  # 修改训练轮数
    "eval_interval": 50,   # 修改评估间隔
    "save_interval": 200,
    "early_stop_threshold": 0.6,
    "patience": 400,
}
```

### 修改环境参数

```python
# 环境配置
env_config = {
    "grid_size": 10,      # 网格大小
    "num_cars": 3,        # 车辆数量
    "max_steps": 350,     # 最大步数
    "max_orders_per_episode": 10,  # 订单数量
}
```

## 🐛 故障排除

### 问题 1: 内存不足

**症状**: 训练过程中崩溃

**解决**: 减少运行次数

```bash
python experiments/rl_comparison_rigorous.py --runs 3
```

### 问题 2: 时间过长

**症状**: 等待时间太久

**方案 A**: 减少 episodes（修改脚本中的 max_episodes）
**方案 B**: 减少运行次数
**方案 C**: 使用 GPU 加速（需要 CUDA）

### 问题 3: 结果不稳定

**症状**: 标准差很大

**原因**:

- 随机种子未固定
- 训练不充分
- 环境随机性过大

**解决**: 增加运行次数到 10 次以上
