# 演示脚本目录

本目录包含各种功能演示脚本。

## 文件说明

- **demo_gui.py** - 基础图形界面演示
- **demo_mapf.py** - MAPF CBS 协调算法演示
- **demo_rl_training.py** - 强化学习训练演示

## 使用方法

```bash
# 运行图形界面演示
python demos/demo_gui.py

# 运行 MAPF 演示
python demos/demo_mapf.py

# 运行 RL 训练演示
python demos/demo_rl_training.py
```

## 注意事项

- 图形界面演示需要安装 pygame
- RL 训练演示需要安装 torch 和 gymnasium
- 演示脚本仅用于展示功能，不建议用于生产环境
