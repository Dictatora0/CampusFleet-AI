# 多智能体系统功能展示与数据采集方案

本方案专注于**系统功能完善与实用性展示**，通过多场景测试自动产出可视化结果和数据，包括：

- ✅ 多场景系统运行数据（不同车辆数、订单规模、调度策略）

- ✅ Web 监控界面与 GUI 仿真截图

## A. 多场景系统功能测试

本阶段展示系统在不同场景下的运行效果，突出功能完善性和实用性。

### A.1 场景 1：小规模基础功能测试

**目标**：展示基本的多智能体协作功能

```bash
# 运行 4 车 + 少量订单的基础场景
python run_with_gui.py --strategy greedy --cars 4 --size 10 --fps 3
```

**操作步骤**：

1. 观察 GUI 窗口中车辆移动和任务执行
2. 等待至少完成 2-3 个订单
3. 截图保存到 `assignment_data/screenshots/scenario1_gui.png`
4. 记录终端输出的统计数据（完成率、平均距离）

**展示重点**：

- 车辆智能体的路径规划（A\* 算法）
- 订单状态变化（待分配 → 已分配 → 配送中 → 已完成）
- 实时统计信息更新

### B.2 创建并运行仿真

```bash
# 创建仿真实例（启用完整数据记录）
curl -X POST http://localhost:8001/api/simulation/create \
  -H "Content-Type: application/json" \
  -d '{
```

## C. 自动数据导出与性能分析

本阶段自动导出所有运行数据，并生成分析用的可视化图表。

### C.1 导出仿真运行数据

```bash
# 导出完整运行日志（CSV 格式）
curl "http://localhost:8001/api/analytics/export" | \
  python -c "import sys, json; data=json.load(sys.stdin); print(data['data'])" \
  > assignment_data/csv_exports/simulation_frames.csv

echo "✅ 已保存运行日志到 simulation_frames.csv"
```

**数据内容**：

- 每个时间步的车辆状态
- 订单完成情况
- 系统性能指标

### C.2 采集多智能体协作数据

在仿真运行期间的不同时刻，采集快照数据：


### C.3 生成性能分析图表

创建一个 Python 脚本自动生成可视化图表：

```bash
cat > generate_analysis_plots.py << 'EOF'
import json
import matplotlib.pyplot as plt
import pandas as pd
from pathlib import Path

# 读取性能数据
perf_20 = json.load(open('assignment_data/json_data/perf_step20.json'))
perf_60 = json.load(open('assignment_data/json_data/perf_step60.json'))
perf_100 = json.load(open('assignment_data/json_data/perf_step100.json'))

# 图 1：完成率随时间变化
steps = [20, 60, 100]
completion_rates = [
    perf_20['metrics']['completion_rate'],
    perf_60['metrics']['completion_rate'],
    perf_100['metrics']['completion_rate']
]

plt.figure(figsize=(10, 6))
plt.plot(steps, completion_rates, marker='o', linewidth=2, markersize=8)
plt.xlabel('仿真步骤', fontsize=12)
plt.ylabel('完成率 (%)', fontsize=12)
plt.title('订单完成率随时间变化', fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('assignment_data/completion_rate_trend.png', dpi=300)
print("✅ 生成图表：completion_rate_trend.png")

# 图 2：车辆利用率对比
vehicle_utils = [
    perf_20['metrics']['vehicle_utilization'],
    perf_60['metrics']['vehicle_utilization'],
    perf_100['metrics']['vehicle_utilization']
]

plt.figure(figsize=(10, 6))
plt.bar(steps, vehicle_utils, color=['#3498db', '#2ecc71', '#e74c3c'], width=15)
plt.xlabel('仿真步骤', fontsize=12)
plt.ylabel('车辆利用率 (%)', fontsize=12)
plt.title('车辆利用率变化', fontsize=14, fontweight='bold')
plt.ylim(0, 100)
plt.tight_layout()
plt.savefig('assignment_data/vehicle_utilization.png', dpi=300)
print("✅ 生成图表：vehicle_utilization.png")

# 图 3：订单处理状态分布
labels = ['已完成', '待处理']
sizes = [
    perf_100['metrics']['completed_orders'],
    perf_100['metrics']['pending_orders']
]
colors = ['#2ecc71', '#e67e22']
explode = (0.1, 0)

plt.figure(figsize=(8, 8))
plt.pie(sizes, explode=explode, labels=labels, colors=colors,
        autopct='%1.1f%%', shadow=True, startangle=90, textprops={'fontsize': 12})
plt.title('最终订单处理状态分布', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.savefig('assignment_data/order_status_distribution.png', dpi=300)
print("✅ 生成图表：order_status_distribution.png")

print("\n📊 所有图表生成完成！")
EOF

# 运行脚本生成图表
python generate_analysis_plots.py
```

**自动生成的图表**：

- `completion_rate_trend.png` - 完成率趋势图
- `vehicle_utilization.png` - 车辆利用率对比图
- `order_status_distribution.png` - 订单状态分布饼图

## F. 一键执行脚本（可选）

为了更方便地执行所有步骤，可以创建一个自动化脚本：

```bash
cat > run_full_experiment.sh << 'EOF'
#!/bin/bash
set -e

echo "🚀 开始完整实验流程..."

# 1. 创建目录
echo "📁 创建数据目录..."
mkdir -p assignment_data/{screenshots,json_data,csv_exports}

# 2. 启动 Web 服务（后台）
echo "🌐 启动 Web 服务..."
cd web_backend
python main.py &
BACKEND_PID=$!
cd ..

sleep 5

cd web_frontend
npm run dev &
FRONTEND_PID=$!
cd ..

sleep 10

# 3. 创建仿真
echo "🎮 创建仿真..."
curl -X POST http://localhost:8001/api/simulation/create \
  -H "Content-Type: application/json" \
  -d '{"grid_size": 10, "num_cars": 4, "strategy": "GREEDY_NEAREST", "enable_logging": true}'

# 4. 添加订单
echo "📦 添加订单..."
for i in {1..10}; do
  curl -X POST http://localhost:8001/api/orders/random
  sleep 0.3
done

# 5. 启动仿真
echo "▶️  启动仿真..."
curl -X POST http://localhost:8001/api/simulation/control \
  -H "Content-Type: application/json" \
  -d '{"command": "start", "params": {"auto_step": true}}'

# 6. 采集数据
echo "📊 采集数据快照..."
for step in 20 60 100; do
  sleep $((step - $(date +%s) + $(date +%s)))
  curl http://localhost:8001/api/agents/status > assignment_data/json_data/agents_step${step}.json
  curl http://localhost:8001/api/communication/logs > assignment_data/json_data/comm_step${step}.json
  curl http://localhost:8001/api/collaboration/decisions > assignment_data/json_data/collab_step${step}.json
  curl http://localhost:8001/api/performance/metrics > assignment_data/json_data/perf_step${step}.json
  echo "  ✅ 已保存步骤 $step 数据"
done

# 7. 导出 CSV
echo "💾 导出运行日志..."
curl "http://localhost:8001/api/analytics/export" | \
  python -c "import sys, json; data=json.load(sys.stdin); print(data['data'])" \
  > assignment_data/csv_exports/simulation_frames.csv

# 8. 生成图表
echo "📈 生成分析图表..."
python generate_analysis_plots.py

echo "✅ 实验完成！请手动截取 Web 界面和 GUI 截图。"
echo "📂 所有数据已保存到 assignment_data/ 目录"

# 清理
kill $BACKEND_PID $FRONTEND_PID 2>/dev/null || true
EOF

chmod +x run_full_experiment.sh
```

运行：`./run_full_experiment.sh`
