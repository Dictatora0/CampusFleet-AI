简介
====

CampusFleet AI 是一个智能校园配送系统，使用多智能体技术实现自主配送车辆的协同调度。

系统架构
--------

核心模块
~~~~~~~~

- **core**: 核心基础设施
  
  - ``logger``: 统一日志系统
  - ``exceptions``: 自定义异常体系
  - ``config``: 配置管理
  - ``decorators``: 性能监控装饰器

- **agents**: 智能体模块
  
  - ``car_agent``: 配送车辆智能体
  - ``order_agent``: 订单管理智能体
  - ``scheduler_agent``: 调度智能体

- **env**: 环境模块
  
  - ``grid``: 网格环境
  - ``pathfinding``: 路径规划算法

- **analytics**: 数据分析模块
  
  - ``data_logger``: 数据记录器
  - ``visualization``: 数据可视化

设计理念
--------

1. **模块化**: 各模块职责清晰，松耦合设计
2. **可测试性**: 完整的单元测试覆盖
3. **可扩展性**: 易于添加新的调度策略和算法
4. **可维护性**: 统一的日志、异常和配置管理

主要特性
--------

多智能体系统
~~~~~~~~~~~~

支持多个自主配送车辆同时工作，通过智能调度算法分配订单。

路径规划
~~~~~~~~

使用A*算法进行单车辆路径规划，MAPF算法处理多车辆协同避碰。

数据记录
~~~~~~~~

完整记录仿真过程中的所有数据，支持导出为CSV格式进行分析。

可视化
~~~~~~

提供Pygame实时可视化界面和数据分析可视化工具。

使用场景
--------

- 校园配送机器人调度
- 仓库自动化搬运
- 多机器人协同作业
- 配送系统仿真研究
